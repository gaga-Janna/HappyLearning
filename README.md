# SceneQuest · HappyLearning

**A story-driven English learning MVP** combining authentic YouTube clips with interactive, original conversations and a personal vocabulary notebook.

## Try the website

Once GitHub Pages is enabled, the expected URL is:
`https://gaga-janna.github.io/HappyLearning/`

To activate GitHub Pages for this repository:

1. Open **Settings → Pages** in this GitHub repository.
2. In **Build and deployment**, choose **Deploy from a branch**.
3. Select branch **main**, directory **/(root)**, then click **Save**.
4. Wait for GitHub Pages to finish publishing, then open the URL above on your phone or desktop browser.

The project uses plain HTML, CSS and JavaScript. No build step is necessary.

## Functional MVP features

- Responsive Discover, Watch, Play, and Notebook screens.
- Real YouTube player embeds using videos published by BBC Learning English and Warner Bros. TV. The video owner may restrict playback or captions in an embedded player.
- Five-minute video selections, a listening-comprehension self-assessment, and saved reflection.
- An original story about Emma, with choices that affect confidence, dialogue, and the ending.
- Browser speech synthesis to read original story dialogue aloud.
- Clickable phrase explanations, Chinese glosses, vocabulary collection, and spaced practice.
- Optional microphone dictation where the browser supports Web Speech Recognition.
- Simple phrase-presence checks for personal sentences, with saved practice and XP.
- Browser-based progress persistence using `localStorage`.

## Important limitations

This is a functional early release, **not** yet a production multi-user platform.

- Accounts, database synchronization, adaptive CEFR testing, and AI feedback are **not implemented**.
- Subtitles belong to the YouTube player. We do **not** extract or claim synchronization with copyrighted transcripts.
- Vocabulary beside the video is independently authored practice content, **not** quoted video dialogue.
- Speech recognition depends on the browser and may be unavailable; typing always works.
- Grammar is **not** graded by AI. Phrase checking only confirms that a saved phrase (or an inflected form) appears in the user's sentence.
- Progress is saved in the current browser only; clearing storage removes it.
- The story is authored content. It is not dynamically generated by AI.
